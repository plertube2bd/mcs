# MC# 튜토리얼

C#을 조금 알고, 마인크래프트 명령어를 한 번쯤 써 본 사람을 위한 학습 과정입니다. 순서대로 읽으면 "빌드는 되는데 게임에서 맞게 동작할까?"라는 의문 없이 MC#을 쓸 수 있게 됩니다.

**이 튜토리얼의 모든 예제는 테스트입니다.** 각 장의 예제는 [`examples/`](examples/) 폴더에 있습니다. 본문에 나온 출력은 `python3 tests/run.py`가 매번 실제로 실행해 확인합니다. 예제를 직접 돌려 보려면:

```sh
mcs run docs/ko/tutorial/examples/t01_hello.mcs
```

## 이 튜토리얼 다음에

- 규칙의 정확한 정의가 필요하면 → [언어 명세](../spec.md). 튜토리얼의 각 장 끝에 관련 명세 조항을 적어 두었습니다.
